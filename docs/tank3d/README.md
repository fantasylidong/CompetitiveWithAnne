# Tank 3D 行为对照

入口：[3D 动画网页](../ai_tank3_3d.html)。无需 npm、构建步骤或外部 CDN；Three.js 0.180.0 和 OrbitControls 随页面保存在 `vendor/`，遵循其中的 MIT LICENSE。

在仓库目录启动：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory docs
```

访问 `http://127.0.0.1:8765/ai_tank3_3d.html`。浏览器需要支持 WebGL 2。页面使用 ES modules，直接双击 HTML 的 `file://` 方式会被部分浏览器的模块安全策略阻止；页面提供本地服务提示。

## 操作

- 左侧选择 12 个场景，右上切换重构后版本 2.0 / 2.1；左侧始终为重构前 1.0.0.13。
- 拖动任一 3D 画面旋转，滚轮缩放，右键拖动平移；触屏可单指旋转、双指缩放。默认同步两边视角，也能分别查看。
- 可切换斜视 / 俯视 / 侧视，显示或隐藏运动轨迹与寻路参考。
- 播放、暂停、循环、0.25–2 倍速；拖动时间轴或点“关键时刻”定位。焦点不在表单控件时，空格播放/暂停，左右箭头逐步调整 0.1 秒。
- 前两个场景支持六档动态难度，以及单独开关 2.1 主动左右连跳。

## 模型边界

这是行为解释工具，不是游戏录像、Source 引擎仿真、真实 nav 寻路、碰撞保证或版本性能基准。旧版动画展示可能出现的不利分支，不意味着旧版每次都失败。2.0 / 2.1 在未涉及新增逻辑的场景中可以表现相同。

`scenarios.js` 保存场景几何、事实说明、关键时刻和确定性轨迹。前两个场景按固定步长计算简化连跳，采用 0.773 秒滞空和当前六档加速/速度上限，以隔离转向差异；两边使用相同难度参数，不宣称复刻旧版所有默认配置。其余场景以关键帧解释状态转换，位移和用时不用于比较实服速度。人物适度放大以便阅读，标签不受地形遮挡。首跳侧向固定以便复看，游戏中首跳随机。

斜视、俯视和侧视展示的是同一三维几何。路径参考是手工输入的解释路线。真正的 NextBot 快照、nav 拓扑、每 tick 探测预算、碰撞体扫描、动画出手时机、攻击伤害和命中判定均不在浏览器中运行。

## 文件

- `../ai_tank3_3d.html`：语义结构与加载失败提示。
- `style.css`：桌面和手机布局。
- `scenarios.js`：情景数据与轨迹采样，无浏览器依赖。
- `app.js`：Three.js 场景、共享时间轴和交互。
- `vendor/`：锁定版本的 Three.js 运行资源与许可证。
