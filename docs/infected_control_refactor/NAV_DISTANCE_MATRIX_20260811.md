# 云58每5%刷特距离与 Director API 测试（2026-08-11）

## 结论

- 57 张官图、每图 `5%..95%`（步长 5%）共 1083 个场景。主矩阵有 1082 场进入刷特并全部 `12/12`；`c5m5_bridge 10%` 在刷特前遇到目标 Nav 无有向路线的已知随机摆位竞态，5 次补测中 3 次成功、2 次同因失败。主统计用最早的成功补测填回该单元格，不重复加权另外 2 次成功。
- 最终主口径为 1083 场、12996 次成功出生：12917 次 `normal_nav`，79 次 `normal_director_range`，0 次 unrestricted，0 次 teleport。
- Director API 共调用 143 次：79 hit、60 miss、4 次请求点超过团队最近距离 2000u 而拒绝；实体落地后的 actual cap reject 为 0。79 次 API hit 与 79 次 Director 成功逐文件、按职业和目标顺序一一对应。
- 所有 12996 次成功均有实际落点的团队最近/最远三维距离。所有 12917 次 Nav 成功都有数值 `navDistance`；所有 79 次 Director 成功均为 `navDistance=N/A`，两种距离没有混算。

## 测试口径

- `teamMinDistance`：实际出生点到所有存活幸存者眼位的最近三维直线距离。
- `teamMaxDistance`：实际出生点到所有存活幸存者眼位的最远三维直线距离。
- `targetDistance`：请求刷点到本次选定目标幸存者眼位的三维直线距离。它不是实际落点到全队的距离。
- `navDistance`：候选刷特 Nav 到目标幸存者 Nav 的有向中心累计路径距离，即 `candidate Nav -> target Nav`；它不是三维直线距离。Director 点没有该值。
- P50/P95 使用矩阵脚本的离散分位数口径：排序后取 `round((n-1)*p)`。

## 完整性与性能

- 1083 个主统计场景全部 `12/12`，共 12996 个 `actualValid=1` 成功实体。
- 实际位置拒绝 103 次，均在后续改选后完成；未混入成功距离样本。
- 12917 次 Nav 出生的可见性违规为 0。另有 14 次 Director 出生被测试探针标记为可见，分布在 6 个高风险场景；Director 本身不承诺沿用 Nav 候选的不可见性筛选。
- 服务端 12 特完成时间：P50 453.1ms、P95 921.8ms、P99 1515.6ms、最大 2125.0ms（`c5m5_bridge 80%`），全部低于 3000ms 目标。
