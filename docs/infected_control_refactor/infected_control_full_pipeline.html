Wave scheduling

击杀阶段、独立倒计时与 Anti-Bait 延长串联执行

专家击杀阶段最多 8 秒；本波较快进入低压且异步队列已完成时会提前启动完整 16 秒倒计时。Anti-Bait 只在倒计时最后 4 秒允许接管，到点后可无限延长，解除条件稳定 2 秒才恢复刷特。

WaveDecider 状态机

每秒由 Timer_CheckSpawnWindow 更新；倒计时到点后调用 StartWave。

Anti-Bait 状态机

下中位数 Flow 判断全队是否推进，四人队需要至少三人移动；单人前探不会重置停滞计时。

Pressure 门槛

持续采样下中位 Flow 与队形，但只在倒计时最后 4 秒进入 Pressure；至少两名有效生还者、无人脆弱、停滞 12 秒且抱团稳定 2 秒才可延长。

无限延长与恢复

16 秒到点仍满足条件便进入 IntensiveCheck，不设最长等待；推进 2%、队形拆组、出现孤立、间距达到 1500 或有人进入脆弱状态，连续 2 秒后立即放波。

保守边界

Anti-Bait 不绕过距离、视线、卡位与路径硬过滤，也不增加单帧 Nav 预算。高点、瓶颈与 Nav 拓扑暂不作为无限延长硬门槛，避免坏 Nav 造成永久误锁。

Class planning

先决定“刷什么”，再进入该职业的距离带

队列以职业上限、当前存活数、已排队数、死亡冷却和本波职业次数为硬边界；稀缺度决定普通优先级，破点波再叠加战术优先级。

API 直出契约

Director 返回坐标后直接调用生成，不再复核有向路径、职业距离、可见性、stuck、伤害区域或 250 直线距离。

实体确认

API 生成后只确认职业、存活和短暂稳定存在；这是生成提交确认，不是第二轮位置安全检查。

失败恢复

两段 API 都无点时轮换目标；目标轮完后按默认 0.10 秒退避，再从职业主区间开始。

06

重新选目标

每次 tick 结束更新目标生还者，避免长期绑定过期目标。

Human infected reservation

内鬼不是额外加人，而是预留并接管一份刷特预算

普通特感在波次 arming window 预留槽；Tank 不占普通 SI 波次槽，等待 ZombieManager 自然生成 AI Tank 后接管。所有玩家提示通过翻译短语输出。

普通特感分支

Traitor_AdjustWaveSpawnBudget 从 AI 本波预算扣除预留数；5 秒内未实体化，槽位归还 AI 队列并提升候补。

Tank 分支

注册后保持 Armed，监听自然 Tank。接管时处理共享槽、Bot 伤害归属和控制权；低伤 Tank 会触发单独封禁。

多生还者 trace + Left4DHooks 可见性；当前实现不包含 PVS 粗筛。

2
NavAreaBuildPath

首次构建最贵，放在可见性之后并复用路径起点和 path cache。

3
Hull stuck 检查

只对通过距离、Flow 和分散过滤的点执行。

4
点位反查 Nav

优先携带 area 索引和已知 bucket，避免重复 nearest-nav native。
